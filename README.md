# OS & Active Directory Project

A hands-on lab demonstrating Windows Server DC setup, Active Directory 
user/group management, and Group Policy configuration.

## Labs

- **Lab 1:** Windows Server 2022 installation and promotion to Domain Controller
- **Lab 2:** Create Organizational Units, users, and security groups
- **Lab 3:** Create and apply Group Policy for password security

## Skills Demonstrated

- OS installation and configuration
- Active Directory infrastructure
- User and group management
- Group Policy Objects (GPO)
- Domain join and authentication
- Troubleshooting

## Architecture

- DC Server (10.0.0.10): Domain Controller running Windows Server 2022
- Client (10.0.0.20): Windows Server 2022 domain-joined client
- Domain: corp.local
- Users: 3 (jsmith, jdoe, tadmin)
- Groups: 2 (SalesTeam, ITTeam)
